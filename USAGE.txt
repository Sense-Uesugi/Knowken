Knowken 1.9.0 · Sense · Windows x64 / GNU/Linux x64
Knowken 1.9.0 发行资料。
随附 Node.js 24.19.0，程序未签名；本地运行，无需 API Key。

简体中文
1. 获取实际发行的完整包。Windows 解压到可写目录后双击 Knowken.exe；GNU/Linux 在可写且可执行目录运行 ./Knowken。
2. 选择语言、字号、次要文字深浅，再查看九主题教程；可跳过或随时重看。
3. 按日期、模型、项目和搜索筛选。统计时区在“更多筛选”或“设置 → 显示与外观”保存；“今天”跟随当地日期。
4. 普通刷新与每 30 秒自动刷新先更新基础统计，运行记录后台整理；基础就绪后可查看任务、导出 CSV 和分享。点击任务查看四类详情，七项运行分析需点击“刷新分析”，同范围旧结果会保留并提示。
5. 可导出 CSV 或预览分享 PNG，分享默认隐藏名称。费用是 USD 假设估算，不是账单。
6. 长期历史不随源日志删除而清空，独立于页面刷新和统计缓存，默认在服务运行时每 5 分钟采集；设置中可暂停、导出、预览并确认合并 JSON。清除须单独确认并暂停采集，不删除原日志。
7. 关闭网页后服务仍运行。Windows 用 Stop-Knowken.cmd／“停止 Knowken.vbs”；GNU/Linux 用 ./Knowken --stop。无桌面用 ./Knowken --no-browser 查看地址。
升级前先导出历史 JSON 和当前价格表，再停止旧版并保留旧目录；不要复制整个 .local、运行状态或用量缓存。详细迁移与系统要求见包内 README.md。

English
1. Obtain an actually released complete package. On Windows, extract it to a writable folder and open Knowken.exe. On GNU/Linux, run ./Knowken from a writable, executable directory.
2. Choose language and readability settings, then review the nine-topic tutorial. You can skip it or reopen it later.
3. Filter dates, models, projects and tasks. Save the statistics time zone in More filters or Settings. Today follows the local calendar date.
4. Manual refresh and 30-second automatic refresh make basic statistics available first while activity records are prepared in the background. You can then open tasks, export CSV and share. Select Refresh analysis to load the seven optional analyses; previous results for the same filters remain with a stale-results notice.
5. Export CSV or preview a sharing PNG; names are hidden by default. USD costs are hypothetical estimates, not invoices.
6. Collected history remains when source logs are deleted. Collection runs every five minutes while the service runs, independently of page refresh and the statistics cache. Pause, export, preview or confirm a JSON merge in Settings. Clearing requires confirmation and pauses collection; original logs remain intact.
7. Closing the page leaves the service running. Stop with Stop-Knowken.cmd on Windows or ./Knowken --stop on GNU/Linux. Use --no-browser without a desktop.
Before upgrading, export history and prices, then stop the old copy and retain its directory. Do not copy the entire .local directory, process state or usage cache. See the package README for migration and system requirements.

日本語
1. 実際に公開された完全なパッケージを取得します。Windows は書き込み可能なフォルダーに展開して Knowken.exe を開きます。GNU/Linux は書き込み・実行可能なディレクトリで ./Knowken を実行します。
2. 言語と読みやすさを設定して、9 テーマのチュートリアルを確認します。スキップや再表示もできます。
3. 日付、モデル、プロジェクト、タスクを絞り込みます。統計のタイムゾーンを詳細フィルターまたは設定に保存できます。「今日」は現地の日付に従います。
4. 通常の更新と 30 秒ごとの自動更新では基本統計を先に表示し、実行記録をバックグラウンドで整理します。基本統計の準備後はタスク、CSV、共有を利用できます。7 項目の任意分析は「分析を更新」で読み込み、同じ条件の以前の結果には古い結果の表示が付きます。
5. CSV と共有 PNG を保存できます。共有では名前を初期状態で非表示にします。USD の費用は仮の推計であり請求額ではありません。
6. 収集済み履歴は元のログを削除しても残ります。ページ更新や統計キャッシュとは別に、サービス実行中は 5 分ごとに収集します。設定で停止、JSON の書き出し、プレビュー、確認後の統合ができます。消去には確認が必要で、その後収集を停止します。元のログは削除しません。
7. ページを閉じてもサービスは続きます。Windows は Stop-Knowken.cmd、GNU/Linux は ./Knowken --stop で終了します。デスクトップがない場合は --no-browser を使用します。
更新前に履歴と価格表を書き出してから、旧版を終了し、旧ディレクトリを保管してください。.local 全体、プロセス情報、用量キャッシュをコピーしないでください。移行と動作条件は README を参照してください。
