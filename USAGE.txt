## 简体中文

筛选与阅读
选择日期、模型、项目，或输入任务搜索词；在“更多筛选”调整日期范围、时区与会话合并。点击任务查看时间线、代理结构和统计详情。在“设置”调整语言、主题、字号、统计显示与用量目标，也可重看使用教程。

运行分析
在首页展开“运行与用量分析”，或在任务详情选择同名分类，再点击“刷新分析”。从总览查看用量、费用估算、任务与模型排行、失败或中断轮次、工具已记录时长和记录关联情况，点击条目进入明细。缺失字段显示“未记录”。普通数据刷新后，按提示重新刷新分析。

费用工具
切换到 API 估算显示，或使用模型模拟比较方案；在“设置 → 价格表”查看、导入或导出价格。费用估算供参考，实际账单为准。“—”表示费用未知，“≥”表示仅能计算部分用量。

导出与分享
CSV 导出对应当前显示的筛选结果；若提示数据已变化，先刷新再导出。分享图片默认隐藏项目与任务名称，保存前可在预览中调整。

历史与备份
在“设置 → 数据与历史”立即采集、暂停采集、导出备份，或预览备份并确认合并。已采集历史可继续查看。需要保存最新用量时，先立即采集再导出备份；确认下载完成，并保管好备份文件。清除历史需要确认，也会暂停采集。

升级
先在旧版导出历史备份与当前价格表，再停止旧版并保留旧目录。将新版完整解压到新目录，预览历史备份，确认范围与数量后合并，按需导入价格表并重新调整偏好设置。启动与停止方法见包内 README.md。

## English

Filters and reading
Choose dates, a model and a project, or search for a task. Use More filters for date ranges, time zones and session grouping. Open a task to view its timeline, agent relationships and statistics. Use Settings to adjust language, theme, text size, statistics display and usage targets, or revisit the tutorial.

Activity analysis
Expand Activity and usage on the home page, or select that category in task details, then choose Refresh analysis. The overview shows usage, cost estimates, top tasks and models, failed or interrupted turns, recorded tool durations and record associations. Select an entry for details. Missing fields show Not recorded. After a basic data refresh, follow the prompt to refresh analysis again.

Cost tools
Switch to API estimate display or compare choices with model simulation. View, import or export prices in Settings → Price table. Cost estimates are for reference; refer to your actual bill for charges. “—” means an unknown cost and “≥” means only part of the usage can be priced.

Export and sharing
CSV exports follow the filters and data currently displayed. If prompted that data has changed, refresh before exporting. Sharing images hide project and task names by default; adjust the preview before saving.

History and backups
Use Settings → Data and history to collect now, pause collection, export a backup, or preview a backup and confirm its merge. Collected history remains available. To include the latest usage, collect now before exporting. Check that the download has finished and retain the backup file. Clearing history requires confirmation and pauses collection.

Upgrading
Export a history backup and active prices from the old version, then stop it and keep its directory. Extract the complete new package into a new directory. Preview the history backup, check its range and count, then merge it. Import prices and adjust preferences as needed. See the package README.md for starting and stopping.

## 日本語

絞り込みと閲覧
日付、モデル、プロジェクトを選択するか、タスクを検索します。「その他の絞り込み」で日付範囲、タイムゾーン、セッションのまとめ方を調整できます。タスクを開くとタイムライン、エージェント構造、統計を確認できます。「設定」で言語、テーマ、文字サイズ、統計表示、使用量目標を調整し、チュートリアルを再表示できます。

実行分析
ホームの「実行と使用量の分析」を開くか、タスク詳細で同名の分類を選び、「分析を更新」をクリックします。概要には使用量、費用推計、上位タスクとモデル、失敗・中断したターン、記録されたツール時間、記録の関連付けが表示されます。項目を選ぶと詳細へ移動できます。不足する項目は「記録なし」と表示します。データ更新後は案内に従って分析を更新してください。

費用ツール
API 推計表示に切り替えるか、モデルシミュレーションで候補を比較します。「設定 → 料金表」で価格を確認、取り込み、書き出しできます。費用推計は参考値です。実際の料金は請求額を確認してください。「—」は費用不明、「≥」は使用量の一部のみ計算できることを示します。

書き出しと共有
CSV は現在表示している絞り込み結果に対応します。データ変更の案内が出た場合は、更新してから書き出してください。共有画像ではプロジェクト名とタスク名を初期状態で隠します。保存前にプレビューで調整できます。

履歴とバックアップ
「設定 → データと履歴」で即時収集、収集の一時停止、バックアップの書き出し、プレビューと確認後の統合ができます。収集済みの履歴は引き続き閲覧できます。最新の使用量も保存するには、即時収集後にバックアップを書き出してください。ダウンロードの完了を確認し、ファイルを保管します。履歴の消去には確認が必要で、収集も一時停止します。

アップグレード
旧版から履歴のバックアップと現在の価格表を書き出し、旧版を終了してフォルダーを保管します。新版を新しいフォルダーに完全展開し、履歴バックアップの範囲と件数をプレビューで確認してから統合してください。必要に応じて価格表を取り込み、表示設定などを再設定します。起動と終了の方法はパッケージ内の README.md を参照してください。
