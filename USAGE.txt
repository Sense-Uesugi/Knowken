Knowken 1.6.0 · Sense · Windows x64 / GNU/Linux x64

简体中文
1. 从 Releases 下载对应平台的压缩包。Windows 解压后双击 Knowken.exe；GNU/Linux 解压 .tar.gz 后在目录中执行 ./Knowken。
2. 选择语言、字号和次要文字灰度，再看简易教程。
3. 选择日期、模型、项目或时区；点击任务查看时间线与会话来源。
4. 可导出 CSV 或保存当前筛选的分享 PNG；设置中可启用每日／每周目标提醒。
5. Windows 使用 Stop-Knowken.cmd 或“停止 Knowken.vbs”退出；GNU/Linux 使用 ./Knowken --stop。无桌面环境可执行 ./Knowken --no-browser，终端会显示地址。
Linux 需要 kernel ≥ 4.18、glibc ≥ 2.28、GLIBCXX ≥ 3.4.25；不提供 ARM 或 musl 包。

English
1. Download the package for your platform from Releases. On Windows, extract it and open Knowken.exe; on GNU/Linux, extract the .tar.gz and run ./Knowken from the extracted directory.
2. Choose your language, text size and secondary text shade, then follow the short tutorial.
3. Select dates, models, projects or a time zone; select a task to view its timeline and sessions.
4. Export a CSV or save a PNG for the current filters; enable daily or weekly page goals in Settings.
5. On Windows, stop with Stop-Knowken.cmd or “停止 Knowken.vbs”. On GNU/Linux, stop with ./Knowken --stop. Without a desktop, use ./Knowken --no-browser to print the address.
GNU/Linux requires kernel ≥ 4.18, glibc ≥ 2.28 and GLIBCXX ≥ 3.4.25. ARM and musl packages are not provided.

日本語
1. Releases から対応するプラットフォームの圧縮ファイルを取得します。Windows は展開後に Knowken.exe を開き、GNU/Linux は .tar.gz を展開してディレクトリ内で ./Knowken を実行します。
2. 言語、文字サイズ、補助テキストの濃さを選び、簡単なチュートリアルに進みます。
3. 日付、モデル、プロジェクト、タイムゾーンを選び、タスクを選択してタイムラインとセッションを確認します。
4. 現在の絞り込みを CSV または PNG で保存できます。設定で日次／週次のページ目標を有効にできます。
5. Windows は Stop-Knowken.cmd または「停止 Knowken.vbs」で終了します。GNU/Linux は ./Knowken --stop で終了します。デスクトップがない場合は ./Knowken --no-browser でアドレスを表示します。
GNU/Linux は kernel ≥ 4.18、glibc ≥ 2.28、GLIBCXX ≥ 3.4.25 が必要です。ARM と musl のパッケージは提供しません。
