# Knowken

**看清你的 Codex Token 用量。**

Knowken 是一款 Windows 本地用量应用，按日期、模型和任务整理 Codex 已记录的 Token 使用情况。开发者：**Sense**。

## 功能

- 每日趋势、模型分布与任务明细。
- 日期和模型筛选、任务搜索、子代理合并、CSV 导出。
- 简体中文、English、日本語；中文支持万 / 亿单位。
- 自定义字号、次要文字深浅和主题色。
- 用量缓存与 30 秒自动刷新。
- 首次阅读设置和简易教程，偏好在本机保存。

## 使用

从本仓库的 **Releases** 下载 Windows x64 发行包，完整解压后双击 **Knowken.exe**。无需安装 Node.js 或下载运行依赖。

首次依次选择语言、字号和次要文字灰度，再跟随三步教程进入应用。关闭网页后，双击 **停止 Knowken.vbs** 或 **Stop-Knowken.cmd** 结束后台运行。

也可使用 **启动 Knowken.vbs** 或 **Start-Knowken.cmd** 启动。发行包内的 **USAGE.txt** 提供三语简短说明。

## 本地与隐私

应用读取当前电脑的 Codex 日志，不上传对话或用量数据，不跨设备同步记录。没有日志时仍可打开应用，使用 Codex 后刷新即可查看。

统计基于现存日志，可能不完整，不等同于官方账单、费用或账号额度。

本仓库用于分发应用及使用说明。第三方组件的许可与来源随发行包提供。当前版本面向 Windows x64，未进行代码签名。
