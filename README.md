# Knowken 2.0.0

## 简体中文

Knowken 是本地 Codex 用量面板，帮助你查看 Token 消耗与任务运行情况。

- 按日期、模型、项目和任务筛选用量，查看趋势与分布。
- 从分析总览进入任务、模型、轮次和工具明细，结合时间线与代理结构阅读记录。
- 查看 API 费用估算、比较模型方案，并设置用量目标。
- 保存用量历史、导出 CSV，或生成默认隐藏名称的分享图片。
- 支持简体中文、英文和日语，可调整主题、字号与统计时区；无需 API Key。

## English

Knowken is a local Codex usage dashboard for viewing Token consumption and task activity.

- Filter usage by date, model, project and task, and explore trends and distributions.
- Open task, model, turn and tool details from the analysis overview, alongside timelines and agent relationships.
- View API cost estimates, compare model choices and set usage targets.
- Retain usage history, export CSV or create sharing images with names hidden by default.
- Use Simplified Chinese, English or Japanese, with adjustable themes, text size and statistics time zone; no API key required.

## 日本語

Knowken は、Token の消費量とタスクの実行状況を確認できるローカルの Codex 使用量ダッシュボードです。

- 日付、モデル、プロジェクト、タスクで絞り込み、使用量の推移と分布を確認できます。
- 分析の概要からタスク、モデル、ターン、ツールの詳細へ移動し、タイムラインやエージェント構造と併せて記録を確認できます。
- API 費用の推計、モデルの比較、使用量の目標設定に対応します。
- 使用履歴の保存、CSV の書き出し、名前を初期状態で隠す共有画像の作成ができます。
- 簡体字中国語、英語、日本語に対応し、テーマ、文字サイズ、統計タイムゾーンを調整できます。API Key は不要です。
