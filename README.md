# Knowken 1.9.0

**看清你的 Codex 用量与运行记录。** 开发者：**Sense**。

Knowken 从本机 Codex 日志和已保存历史整理 Token 用量，按日期、模型、项目和任务查看统计。支持简体中文、English、日本語，无需 API Key 或云端服务。

**1.9.0 发行资料**，面向 Windows x64 和 GNU/Linux x64。实际可下载版本以 Releases 为准。

## 功能

- 日期、模型、项目和任务筛选，主／子代理合并、任务时间线与代理结构。
- API 估算费用、缓存分项、本地价格 JSON、模型费用模拟和页面用量目标。
- 独立长期用量历史、后台采集、历史 JSON 导出、预览和确认合并。
- 逐轮费用、模型与推理强度、日志额度快照、任务与工具耗时、上下文与压缩、计价与覆盖诊断、分叉与委派记录。点击“刷新分析”加载。
- 保存统计时区，支持跟随系统；“今天”在跨午夜刷新后跟随当地日期，地区夏令时按当地规则计算。
- 当前筛选的 CSV 和分享 PNG；分享默认隐藏任务与项目名称。
- 字号、次要文字深浅、主题、语言与单位设置，以及九主题教程。

## 刷新与长期保留

普通刷新与每 30 秒自动刷新先更新基础统计；基础数据就绪后即可查看任务、导出 CSV 和分享，运行记录继续在后台整理。页面显示“后台整理中”时仍可使用基础功能。七项运行分析仅在点击“刷新分析”时计算，并等待对应刷新轮次的运行记录；同一筛选下保留上次分析并提示旧结果。自动刷新仅在页面可见且没有读取、手动分析或弹窗操作时运行。

长期历史默认每 5 分钟采集，独立于页面自动刷新和统计缓存。关闭网页后只要服务仍运行就继续采集；已采集记录不会随源日志删除而清空。设置中可导出、预览并确认合并历史 JSON，暂停采集也会保留已有记录。

## 运行

发行目标为 Windows x64 和 GNU/Linux x64；从 [Releases](https://github.com/Sense-Uesugi/Knowken/releases) 获取实际已发布的完整包。Windows 解压到可写目录，双击 `Knowken.exe`；GNU/Linux 在可写且允许执行的目录运行 `./Knowken`。完整操作和升级保护见对应包内 README 与 USAGE.txt。

关闭网页后服务继续运行。Windows 使用 `Stop-Knowken.cmd` 或“停止 Knowken.vbs”；GNU/Linux 使用 `./Knowken --stop`。没有桌面时用 `./Knowken --no-browser`，再手动打开本机地址。无需单独安装 Node.js。

## 本地数据与统计边界

服务只监听 `127.0.0.1`。应用只读 Codex 日志与任务名称数据库；自有历史、缓存、偏好和价格状态保存在本机。不保存对话正文、命令、工具参数、输出、附件或认证信息，不上传数据，不自动跨电脑同步。

已采集历史不随源日志删除而清空；保存日期不证明账号记录完整。首次采集前丢失且无有效备份的资料无法补回。额度是日志快照，耗时是日志观测，均不能当作实时账号查询或人工工作时间。

所有费用为同一批 Token 按当前启用目录的假设 USD 换算。内置表 `2026-10-03.1` 保留原核价日期，不联网刷新；未知金额显示“—”，部分覆盖显示已知下限“≥”。估算、模型模拟和目标均不等于实际账单、订阅费用、实际节省或官方额度。
