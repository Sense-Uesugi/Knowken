# Knowken

**了解你的 Codex 用量。**

按日期、模型、项目和任务查看 Token 使用情况，也可以切换到 API 估算费用，或同时显示两者。

**Windows x64 · GNU/Linux x64**  
**简体中文 · English · 日本語**  
**开发者：Sense**

[下载最新版](https://github.com/Sense-Uesugi/Knowken/releases/latest)

## 可以用它做什么

- 查看每日用量、模型分布、项目统计和任务明细。
- 比较本周、本月与上期同期的用量。
- 查看任务的小时用量时间线与主／子会话来源。
- 导出当前筛选范围的 CSV，或生成默认隐藏任务和项目名称的分享图片。
- 设置每日、每周 Token 目标，在页面中查看进度提醒。
- 调整语言、字号、文字深浅、主题色和深浅色模式。

## 1.7.0 新增

Token、API 估算费用和双显模式；有缓存时优先显示上次统计；项目和任务表格支持自动及手动列宽。

## 开始使用

1. 从 Releases 下载与你的系统匹配的发行包，完整解压到当前用户可写的目录。
2. Windows 双击 `Knowken.exe`；GNU/Linux 运行 `./Knowken`。
3. 首次选择语言、字号和文字深浅，跟随简易教程开始使用。

无需另行安装 Node.js。详细操作见 `USAGE.txt`；系统要求和实测范围见 [1.7.0 发布说明](https://github.com/Sense-Uesugi/Knowken/releases/tag/v1.7.0)。两个发行包均未签名。

## 本地数据

Knowken 读取当前电脑的 Codex 日志，不上传对话或用量数据，也不跨设备同步。统计范围取决于本机现存日志，可能不完整。
